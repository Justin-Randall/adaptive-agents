## Agreed Design Direction

- The event ledger is authoritative; Markdown indexes and context packets are derived model-facing views.
- The model determines topical relevance, context-packet boundaries, semantic labels, and recursive index decomposition.
- The root index is a topic-of-topics. Graph depth is unbounded when additional narrowing is needed, but each node and retrieval step should remain context-budget safe.
- Reachability, source identity, link integrity, non-orphaning, and update safety are deterministic invariants. Semantic quality is evaluated through dogfood and retrieval evidence.
- Provider context telemetry is optional. Missing telemetry triggers conservative heuristics and rebalancing diagnostics, never detail loss or automatic feature failure.
- The session `INDEX.md` seed template is a separate versioned artifact with bounded managed regions and preserved model-authored regions.

## R&D Questions

- Choose context packet versus turn-bundle boundaries and document the evidence.
- Establish reliable event grouping and multi-source provenance.
- Define measurable semantic-coverage evaluation without pretending the validator can certify meaning.
- Select local size/density heuristics for providers with opaque context budgets.
- Define template versioning, compatibility, and migration behavior.

- Retrieval simplification decision: an intermediate context-packet file is not automatically justified. When the model can express the topic, why it matters, exact JSONL line range, and link in one index entry, that direct entry is the preferred one-hop path. Sub-indexes remain useful for keeping large indexes within context budget, but they should preserve the same direct locator contract. Derived packets are optional only when they add genuinely useful bounded summaries that cannot fit economically in the index entry; they must not become mandatory traversal steps.
- Hierarchical index clarification: an index is not “direct JSONL links or sub-index links.” At every level, entries may mix direct locators with purposeful delegation. For example, one entry may say “Read `ledger.jsonl` lines 121–155,” while another says “Topics related to installer permissions are organized in [the installer-permissions index](...)”. The delegation text should name the topic boundary and tell the model why to follow it; narrower indexes use the same mixed-entry contract recursively.
