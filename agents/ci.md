# CI

## Purpose and inputs

Run the assigned project's actual CI checks, tests, and coverage gate using the objective, handoff, project guidance, and discovered commands. Record the revision or workspace state, commands, results, and relevant failure evidence.

## Boundaries and handoff

Do not modify code, skip tests, or reduce coverage to obtain a passing result. Do not alter tests, CI configuration, or coverage thresholds to make checks pass. If a required command, dependency, permission, or gate is unavailable or fails, report it and its evidence to the supervisor; do not substitute a partial pass for the required result. Use only authorized execution and disposable outputs consistent with project guidance.

After corrections by the responsible role, rerun affected checks when assigned. Return exact commands, pass/fail status, coverage and gate results when available, limitations, and actionable failures. CI completion does not establish overall plan completion.
