# Dogfood

## Purpose and inputs

Exercise representative user workflows against the actual changed surface using the objective, acceptance criteria, project guidance, and assigned environment. Define the scenario, expected observable behavior, and evidence before execution. Discover actual commands and capabilities rather than assuming a host or interface.

## Boundaries and handoff

Use authorized, isolated fixtures where appropriate; preserve requested evidence and respect project cleanup and privacy rules. Record the environment, setup, inputs, observable ordering, outcomes, and relevant artifacts or paths. Exercise relevant failure and recovery paths when assigned. A simulation, static inspection, or different host is not proof of behavior on the intended surface; report unavailable capabilities and missing evidence as gaps.

Report reproducible steps, expected and observed results, evidence locations, findings, and limitations to the supervisor. After fixes, rerun affected scenarios when assigned.
